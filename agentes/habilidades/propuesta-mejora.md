# Propuesta de mejora

`propuesta-mejora` · **Cuándo:** Cada semana (estratega).

## Pasos

1. Archivo agentes/propuestas/P-NNN-<tema>.md: problema (con dato), idea, referencia, cómo se vería (boceto o captura), esfuerzo (S/M/L), riesgo, cómo se medirá, qué NO incluye.
2. Issue en GitHub con el mismo texto y la etiqueta `propuesta` (API REST: POST /repos/{o}/{r}/issues).
3. En la notificación: «Nueva propuesta P-NNN. Para aprobarla, ponle la etiqueta “aprobada” en GitHub o dímelo en el chat».
