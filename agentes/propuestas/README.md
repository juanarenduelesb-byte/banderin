# Propuestas de mejora

Las escribe el agente estratega: una por semana como máximo y nunca más de 3 abiertas sin respuesta.
Cada propuesta es un archivo `P-NNN-tema.md` y un issue en GitHub con la etiqueta `propuesta`.

**Para aprobar:** pon la etiqueta `aprobada` en el issue (o `rechazada`). Los comentarios que escribas mandan sobre la propuesta.
El estratega construye lo aprobado el jueves siguiente y cierra el issue con capturas.
